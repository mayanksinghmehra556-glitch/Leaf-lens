# 🌿 LeafLens

LeafLens is a simple web-based plant leaf health detection prototype.  
Users can capture or upload a leaf image and view an interactive health analysis.

## 🚀 Live Demo

👉 **[Try LeafLens](YOUR-VERCEL-LINK-HERE)**

## ✨ Features

- Capture a leaf using your camera
- Upload a leaf image
- Interactive analysis animation
- Healthy, Slightly Contaminated, and Damaged results
- Responsive and modern UI

- JavaScript
